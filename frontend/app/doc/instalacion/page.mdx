# Instalación

Añade el SDK a tu proyecto Java mediante Maven o Gradle. El artefacto está publicado en Maven Central y no requiere repositorios adicionales.

## Requisitos previos

- **Java 17 o superior** — cualquier distribución (OpenJDK, Temurin, GraalVM)
- **Certificado P12** — emitido por el Banco Central del Ecuador (BCE)
- **RUC válido** — 13 dígitos, verificado con módulo 11

No se requiere configurar repositorios adicionales. Maven Central está incluido por defecto en Maven y en la mayoría de configuraciones de Gradle.

## Verificar la instalación

Después de añadir la dependencia y ejecutar la descarga (`mvn install` o `gradle build`), verifica que el classpath incluye las clases del SDK:

```java
import io.github.opensri.api.builders.client.OpenSRIClientBuilder;
import io.github.opensri.domain.enums.Environment;
```

Si el proyecto compila sin errores de importación, la instalación es correcta.
