public class EjemploFactura {

    public static void main(String[] args) throws Exception {

        // 1. Cargar el certificado de firma
        byte[] cert = Files.readAllBytes(Paths.get("certificado.p12"));

        // 2. Perfil del emisor

        );

        // 3. Crear el cliente
        OpenSRIClient client = OpenSRIClientBuilder.builder()
            .environment(Environment.PRUEBAS)

            .certificatePassword("mi-contraseña")
            .certificateAlias("mi-alias")
            .issuerProfile(issuerProfile)
            .timeout(30)
            .build();

        // 4. Datos del emisor para la factura
        Issuer issuer = new Issuer("MI EMPRESA S.A.", new Ruc("1791248678001"));
        TaxInfo taxInfo = new TaxInfo(1, issuer, "Av. Amazonas N37-29");
        DocumentNumber docNumber = new DocumentNumber("01", "001", "001", "000000001");

        // 5. Comprador
        Client buyer = new Client(new NationalId("1234567890"), "JUAN PÉREZ");

        // 6. Ítem de la factura (IVA 0%)
        InvoiceItem item = new InvoiceItem(
            "P001", null, "Servicio de consultoría",
            BigDecimal.ONE,
            new BigDecimal("100.00"),
            BigDecimal.ZERO,
            new BigDecimal("100.00"),
            List.of(),
            List.of(new Tax("2", "0", BigDecimal.ZERO, new BigDecimal("100.00")))
        );

        // 7. Construir la factura
        var invoice = InvoiceBuilder.builder()
            .issueDate(IssueDate.now())
            .establishmentDirection("Av. Amazonas N37-29")
            .taxInfo(taxInfo)
            .documentNumber(docNumber)
            .documentVersion(DocumentVersion.VERSION_100)
            .client(buyer)
            .addItems(List.of(item))
            .addPayments(List.of(new ImmediatePayment(
                PaymentMethod.SIN_SISTEMA_FINANCIERO, new BigDecimal("100.00"))))
            .build();

        // 8. Enviar al SRI
        SendInvoiceResult result = client.sendInvoice(invoice);

        System.out.println("Clave acceso: " + result.accessKey());

        Thread.sleep(3000);
        var auth = client.checkAuthorization(result.accessKey());
        System.out.println("Autorización: " + auth.authorization().status()); // AUTORIZADO

        Files.writeString(Paths.get("factura-" + result.accessKey() + ".xml"), result.signedXml());
    }

## Buenas prácticas

- **Reutiliza el cliente** — `OpenSRIClient` es thread-safe. Crea una instancia por emisor al inicio de la aplicación.
- **No guardes el P12 en el repositorio** — usa variables de entorno o un gestor de secretos.
- **Número secuencial único** — el SRI rechaza comprobantes con el mismo número secuencial. Asegúrate de incrementarlo correctamente.
- **Maneja `DEVUELTA`** — siempre revisa `result.response().status()` antes de asumir que el comprobante fue aceptado.
- **Guarda el XML firmado** — `result.signedXml()` es la evidencia legal del comprobante enviado.

<Callout type="warning">
El SDK actualmente soporta únicamente el ambiente de pruebas (`Environment.PRUEBAS`). El soporte de producción está en el roadmap.
</Callout>
